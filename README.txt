IMPORTANT:
This package intentionally does NOT replace app.js, Firebase configuration, styles, renderers, or any other existing feature.

1. Upload permanent-delete-guard.js to the same folder as index.html.
2. In your EXISTING index.html, add this one line immediately before </body>:
   <script src="permanent-delete-guard.js?v=20261102-v2"></script>
3. Commit/deploy.
4. Hard refresh the page.

Do not replace your existing index.html with INSTALL.html. INSTALL.html is only an installation reference.
